# 사례 슬롯별 보고서 계산에 추가로 필요한 입력

A–D는 가상 사례 저장 슬롯이다. 각 슬롯은 B 또는 B′ 전략과 월 생활비, 유족연금, 신탁 순실질수익률, 부모 재취업 월소득, 자녀 설계 종료 나이의 변경값을 저장한다. 아래에서 A·D 전략은 보고서 표 9의 대안 이름으로 쓴다.

## 표 7 재무비율 진단

| 지표 | 슬롯에서 추가로 받아야 할 값 또는 확정할 규칙 |
| --- | --- |
| 가계수지지표 | 진단 기준월 또는 기준연도, 부모 가계의 세후 총소득과 총지출. 신탁 납입, 퇴직급여, 부채 상환을 총액에 포함하는 기준 |
| 비상자금지표 | 기준일 즉시 사용할 수 있는 현금성 자산과 기준월 지출. 신탁 재산, 예금, 투자자산의 포함 범위 |
| 총부채상환지표 | 부모 가계의 연간 부채 원금과 이자, 기준연도 세전 근로소득. 어떤 채무와 어떤 부모의 소득을 합산할지 |
| 총저축성향지표 | 연간 저축액과 세전 근로소득, 부모 몫과 자녀 몫의 저축 구분, 신탁 납입을 저축으로 분류할지 |
| 부모 사후 생활비 준비율 | 진단 시점에 지훈 씨 몫으로 확보된 재원, 표 7 분모의 부모 사후 부족액 산정 기간과 가격 기준. 시뮬레이터의 56세 필요 잔액과 같은 개념으로 볼지 확인 |
| 조기 사망 보장 충족률 | 조기 사망 기준 연도, 해당 시점의 적립액·보험금·지훈 씨 순상속 몫, 그 시점부터의 필요 잔액. 부모 사망 순서에 따른 자산 배분과 중복 합산 방지 규칙 |

현재 화면은 표 7 원문을 고정 참고값으로 표시한다. 슬롯별 56세 필요 잔액 충당률과 첫 인출 연도의 생활비 충당률은 기존 엔진 결과에서 별도로 계산한다.

## 표 9 대안 비용과 최대 후회

- 기대 경로, 어머니 먼저 사망, 25세 사고, 95세 생존 각각의 사건 시점과 부모 사망 순서, 사건 직후의 부모 금융자산·주택 순자산·자녀 신탁 시작 잔액을 확인해야 한다.
- 사건별로 B/B′의 납입·보험금·상속·사후 보충 중 무엇이 언제 발생하는지 확정해야 한다. A·D 전략을 동적으로 비교하려면 그 전략의 자산 이전과 급여 경로도 필요하다.
- 보고서 식 4의 공적급여 손실을 계산할 비교 기준 경로, 기간, 집계 방식과 슬롯의 설계 종료 나이가 보고서의 사건 종료 나이와 다를 때의 우선순위를 정해야 한다. 사건별 비용을 계산한 후 같은 사건의 최저 비용과 비교해 최대 후회를 구한다.

현재 화면은 각 슬롯에 대해 동일 입력의 B/B′ 필요 잔액, 예상 잔액, 생활비 부족액, 부모 금융자산 최저를 비교한다. 표 9의 사건별 비용과 후회는 고정 참고값으로 구분한다.

## 그림 9 착수 후 180일 일정

- 슬롯별 착수일, 대상 기관과 담당, 선택한 신탁·보험의 계약 조건, 서면 회신·인수 심사·후견 절차에 필요한 예상 기간이 필요하다.
- 각 작업의 선행 조건, 병렬 진행 여부, 대기 기간, 재계산 결과에 따라 업무를 추가하거나 제외하는 기준이 필요하다.
- 세무·신고 업무는 기산 사건과 적용 기한, 달력일·영업일 구분, 휴일 처리 기준을 기관과 확인해야 한다. 가족 또는 기관이 입력한 실제 진행 상태와 예상 일정의 관계도 정해야 한다.

현재 화면은 보고서의 착수일 기준 0~180일 구간을 표시한다. 선택 슬롯의 필요 잔액·예상 잔액·최초 부족 연도는 상담과 재계산에 가져갈 값으로 연동한다.
