# P1 구현 계약 · 2026-11-09

사용자가 선택한 범위: **민감도 분석·사례 비교·근거 내보내기**. P0의 가상 계산 계약과 기존 `/api/simulations`를 그대로 사용한다. 급여 모형 정밀화·사망/상속 동적 계산·서버 저장은 이번 P1에 포함하지 않는다.

## F08 민감도 분석

- 적용된 가상 입력 중 한 필드만 바꿔 하한/현재/상한을 비교한다. 나머지 입력은 고정한다.
- 기본 구간은 월 금액 ±20%(최소 변화 10만 원), 수익률 ±0.5%p, 종료 나이 ±5세이며 입력 허용 범위로 제한한다. 사용자가 범위 안에서 구간을 편집할 수 있다.
- 중복 값은 한 번만 계산한다. 하한≤현재≤상한, 기존 필드 단위/정밀도를 검증한다.
- 각 변형의 B/B′를 기존 서버 API로 계산한다. 필요 잔액, 56세 예상 잔액, 부족액, 부모 최저값, 기준 대비 차이를 보여 준다. 불가능한 필요 잔액은 미지원 상태로 유지한다.
- 입력/전략/구간이 바뀌면 오래된 분석을 현재 결과처럼 표시하지 않는다. 실패/취소 시 수동 계산과 다른 P0 기능을 유지한다.

## F09 사례 비교

- 적용된 계산을 최대 3개 비교 카드로 고정하고 현재 계산과 나란히 비교한다. 전략·다섯 입력·가정 버전·지표를 구별한다.
- 같은 사례/전략/입력/가정의 중복 고정은 막고 삭제할 수 있다. 자유로운 개인정보/이름 입력은 제공하지 않는다.
- 비교 카드와 계산 결과는 **현재 탭 메모리에만** 둔다. localStorage에는 기존 계약대로 적용 입력과 전략만 저장한다. 새로고침과 초기화 시 비교 카드·민감도 결과를 삭제한다.

## F10 근거 내보내기

- JSON 근거 묶음: 가상 사례 ID, 2026년 기준, 출처/가정 버전, 입력과 단위, 선택 전략, 연도별 결과, 원 단위 지표, 계산 근거와 미확인 한계. 유효한 비교 카드/민감도 분석도 포함한다.
- CSV 연도표: 선택 전략의 부모/자녀 경로를 원 단위로 제공하며 CSV 구조와 숫자 타입을 보존한다.
- 독립 HTML 보고서: 입력·지표·근거/가정·연도표를 사람이 읽고 인쇄할 수 있게 제공한다. 외부 리소스나 API 키, 자연어 원문을 포함하지 않는다.
- 모든 파일은 사용자의 클릭으로 브라우저에서 생성한다. 서버 저장·업로드·자동 다운로드는 하지 않는다. 편집 중 값이나 확인 전 LLM 제안 대신 적용된 계산만 내보낸다.

## 완료 게이트

지원 입력 경계, 중복/최대 카드, 분석 무효화, 수치 차이·미지원 전파, 내보내기 데이터/CSV/HTML 안전성을 시험한다. 기존 P0 시험을 유지하고, 공개 Vultr URL에서 분석→사례 고정→변경·비교→내보내기→새로고침/초기화를 실제로 확인한다.
