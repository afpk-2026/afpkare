# 그래프·정보 밀도 개선 검증 · 2026-11-09

프론트0.3.1. 계산/API/저장 계약 변경 없음. 신규 런타임 의존성 없음.

- 실제 Chrome의 부모 그래프에서 포인터를2046→2055년으로 이동할 때 툴팁 연도와 원 단위 B/B′ 잔액이 함께 바뀜을 확인.
- 키보드 Home/End/좌우 화살표로 연도 탐색.2031년 B233,823,027원·B′264,429,057원을 API와 대조. 비교 경로가 없는 해는0원 대신 ‘해당 연도 경로 없음’ 표시(종료56세 현재 경로와95세 기준 비교).
- 두 그래프를 같은 시간축으로 재생·일시정지·전체보기·주요시점/슬라이더 이동.2062년 선택 시 부모 clip폭510·자녀244.8로 동일 연도 반영.2030년에 일시정지 후 값 유지. 입력 적용 후 처음부터 재생됨.
- 애니메이션은 선을 드러내는 화면 효과로만 구현. 툴팁은 보간/임의 숫자 없이 실제 연도 행을 표시. 재생 연도에 따라 계산 지표를 중간 결과로 바꾸지 않음.
- 시스템 prefers-reduced-motion은 자동 재생을 끄도록 구현·코드 확인. 이 OS 설정 자체를 변경하는 수동시험은 하지 않음.
-390px 실제 뷰포트에서 툴팁·재생 제어·세로 그래프 확인. document clientWidth=scrollWidth=390, 전체 가로 넘침 없음. 임시 viewport 설정 복원.
- 생활비1000만·유족연금0 입력: 충족비율 ‘계산 미지원’, 부모 최저 음수, 부족40/40년. NaN/Infinity없음. 비용185만은93%·부족4/40년으로 실제 API 요약 반영.
- 필요/예상 잔액 막대·부족연도 히트맵·보고서 비교 카드·민감도 동일축 막대·사례 요약 카드로 긴 설명/큰 표를 대체. 전체 표·산식·개인정보 안내·기관/상품 미확인 근거는 접기/펼치기로 보존.
- frontend19시험·TypeScript/Vite 빌드 통과. 계산 원본·서버 인증·배포 설정은 수정하지 않음.
