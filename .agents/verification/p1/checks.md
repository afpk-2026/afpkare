## 실제 Chrome 및 파일 검증

- 다섯 필드의 한 번에 한 입력 변화 구간. 생활비 및 수익률 민감도를 공개 URL에서 실행, 각 구간의 B/B′ 숫자 확인.
- 입력 적용 또는 분석 필드/구간 변경 시 이전 민감도 표 삭제 확인. 잘못된 하한/현재/상한 순서는 오류로 거부.
- 고정 사례 3개, 중복 차단, 4번째 추가 제한을 로컬 Chrome에서 확인. 공개에서 B 180만/B 185만/B′ 185만 세 카드 비교.
- 공개 새로고침 후 카드·분석은 사라지고 적용된 185만·B′만 복원됨.
- 실제 JSON 다운로드: 현재 계산 + 비교 카드 3개 + 민감도 3구간×2전략. 총 10건의 summary/child_timeline/parent_timeline/source_refs/warnings를 공개 계산 API와 대조해 모두 일치.
- 편집창 220만 원을 적용하지 않은 상태에서 다운로드했으며 JSON에는 적용된 185만 원만 포함됨.
- 실제 CSV 다운로드: 부모37+자녀76=113행. 모든 행의 연초+유입−유출+수익=연말 확인. 원 단위 정수, 음수 부모 자산, null/미지원 보존을 시험함.
- 로컬 HTML 다운로드·구문·브라우저 렌더 확인. 수치/근거/미확인 상태/계산 계약 원자료와 전체 연도표 포함. 스크립트 태그 0, 외부 리소스 없음, 모든 표의 열 개수 일치.
- 다운로드 대기 도구의 연결이 끊겼지만 JSON 파일은 실제 생성됨을 파일시스템에서 확인했다. 이후 다운로드는 클릭 후 실제 파일을 검사하는 방식으로 확인.

## 최종 공개 HTTPS 검증

- 사용자에게 HTTP HTML 다운로드 완료를 확인받았다. 초기 파일 관측 실패만으로 브라우저 차단으로 단정할 수 없으며, Chromium 원인 추정은 확정하지 않는다.
- 사용자 승인으로 무료 IP HTTPS를 추가. 최종 URL https://158.247.203.92/ · 릴리스 p1-cbe8301 · 기존 scenario-2026-11-09-v1 유지. 별도 진행 중인 보고서 재현 엔진 변경은 사용자 선택에 따라 배포에서 제외하고 보존했다. 배포 소스는 Git 커밋 스냅샷만 사용했다.
- Terraform plan 검토 후 443 규칙1추가·설명1변경·삭제0. 서버 교체/추가 유료자원 없음. 기존 월$10.
- Let's Encrypt 공인 IP SAN 인증서 확인. nginx TLS1.2/1.3·HTTP 유지. Certbot staging 검증, 실제 발급, 갱신 dry-run+deploy hook의 nginx 검사·reload 성공. 하루2회 systemd timer 활성. 미래 실제 자동 갱신은 운영 감시 대상.
- HTTPS Chrome F06 생활비185만 적용, F07 실제83세 제안 확인·적용, B/B′, 비교2카드, 민감도3구간×두 전략, 새로고침 시 카드/분석 삭제·적용 설정 복원, 초기화 후 기본180만/B 유지 확인.
- HTTPS HTML 실제 다운로드29274바이트 확인. 필요액196,373,279원, 계약 버전, 표150행, 외부 리소스·실행스크립트0. `https-report.html`과 해시 기록 참조.
- 최종 HTTPS API 회귀는 기준/변경 B/B′,65세 전환, 입력오류422, 인출한도 미지원null, 개인정보 문장 거부, 실제 Upstage 제안까지 통과(`https-p0-regression.json`).
